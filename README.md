
# Secure Network Monitoring & Anomaly Detection Platform

## Overview
A backend-first monitoring platform that analyzes protocol-level traffic and logs to extract performance metrics, detect anomalies, securely store results, and expose insights through REST APIs and dashboards.

## Architecture
- Data Ingestion (PCAP / CSV)
- Analysis & Anomaly Detection
- Secure Storage (Encryption + Integrity)
- REST API Backend
- Web Dashboard (Phase 4)
- Android App (Phase 5)

## Tech Stack
- Python, Flask
- Pandas, Scapy / PyShark
- Cryptography (AES, SHA-256)
- PostgreSQL
- HTML/CSS, Chart.js

## Project Status
